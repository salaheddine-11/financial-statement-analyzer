
# Moroccan Financial Statement Analyzer

A Streamlit prototype for analyzing Moroccan financial statements using CGNC-based logic.

The project will transform raw accounting data into:

- Standardized financial statements
- Bilan comptable
- Bilan financier
- Retraitements and reclassements
- FRF / BFG / Trésorerie nette
- ESG indicators
- Financial ratios
- Red flags

## Disclaimer

Prototype for educational purposes only. Does not replace professional judgment, audit work, or financial advisory.

## Accounting basis

Moroccan statutory financial statements are generally prepared using historical cost.
Book values may differ from economic values.
